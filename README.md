# 🎵 Trackscout

**A music discovery app built with React and the Deezer API.**

_Work in Progress – Features and UI are actively being improved!_

Trackscout lets you search for tracks, and preview songs directly from the Deezer catalog. Built as a learning project to master **React, API integration, and modern frontend tools**.

🔗 **[Live Demo](https://trackscout-ashy.vercel.app/)** (Hosted on Vercel)

---

## 🛠️ **Technologies Used**

| Technology       | Purpose                                                |
| ---------------- | ------------------------------------------------------ |
| **React**        | Frontend framework for dynamic UI components.          |
| **Vite**         | Fast build tool for React (replaces Create React App). |
| **Tailwind CSS** | Utility-first CSS framework for rapid styling.         |
| **Deezer API**   | Music data (tracks, albums, artists, previews).        |
| **Vercel**       | Hosting for static frontend deployments.               |
| **GitHub**       | Version control and collaboration.                     |

---

## 🎨 **Design & UX Choices**

### **Minimalist UI**

- **Dark theme** with blue accents for a modern, audio-friendly look.
- **Card-based layout** to highlight album art and track details.
- **Subtle animations** (hover effects, transitions) for better interactivity.

### **User Flow**

1. **Search bar** at the top for quick track/artist lookups.
2. **Track cards** displaying:
   - Title, artist, and album info.
   - Duration.
   - Play/pause buttons for 30-second previews.
3. **Responsive design** for mobile/desktop use.

### **Why This Design?**

- Focus on **music discovery** without clutter.
- **Visual hierarchy** to emphasize album art and track titles.
- **Accessibility**: High contrast for readability, keyboard-navigable buttons.

## 🎯 **Features**

### ✅ **Current Features**

- Search tracks/artists via the Deezer API.
- Play 30-second previews (where available).
- Display track duration, album art.
- Responsive design for all devices.

### 🚀 **Upcoming Features (Work in Progress)**

- Year of release, lyrics, album infos.
- User playlists (save favorite tracks).
- Advanced filtering (by genre, decade, mood).
- Improved error handling for missing previews.

---

## 💡 **Why This Project?**

### **Learning Goals**

- Master **React hooks** (`useState`, `useEffect`, `useRef`) for state management.
- Practice **API integration** (fetching, error handling, data normalization).
- Experiment with **Tailwind CSS** for rapid UI development.
- Deploy a **static frontend** on Vercel with zero backend.

### **Challenges Overcome**

- **CORS issues**: Used proxy solutions to bypass API restrictions.
- **State management**: Managed audio playback across multiple track cards.
- **Responsive design**: Ensured usability on mobile and desktop.
- **Deployment quirks**: Debugged Vercel build configurations.

### **For the Community**

Trackscout is open-source to help others learn:

- How to integrate **music APIs** in React.
- How to handle **asynchronous data** (loading states, errors).
- How to deploy a **static React app** with Vercel.
